Voce dell'Istruttore

Genera tutte le frasi di FitLoo con la tua voce clonata su ElevenLabs. Tutto avviene nel tuo telefono: la chiave non viene inviata a nessuno tranne ElevenLabs.

Come fare, passo per passo

  1. Crea la tua voce. Vai su elevenlabs.io, accedi e apri Voices › Add a new voice › Instant Voice Clone. Carica una o più registrazioni pulite della tua voce (almeno 1–2 minuti, senza musica). Conferma di avere il diritto di usare quella voce: deve essere la tua.
  2. Crea una chiave API. Clicca sul tuo profilo (in basso a sinistra) › API keys › Create API key. Copia la chiave (inizia di solito con sk_).
  3. Incollala qui sotto, premi Carica le mie voci e scegli la tua voce. Premi Prova per sentire un esempio, poi Genera tutto.
  4. Invia lo zip. Alla fine scarica (o condividi) il file voce-istruttore.zip e mandalo nella chat con Claude.

Nota: i piani gratuiti di ElevenLabs potrebbero non includere la clonazione della voce o non avere abbastanza caratteri per tutte le frasi. Se ti fermi a metà, nessun problema: i clip già fatti restano salvati e, premendo di nuovo Genera, si riparte da dove eri rimasto.
